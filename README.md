# DropBoard Lite

**Drop a CSV file. Get an instant dashboard.** No install, no account, no internet needed — your data never leaves your machine.

▶ **[Try it live in your browser →](https://goodyuanbo.github.io/dropboard/)** (or download `DropBoard-Lite.html` below)

DropBoard Lite is the free, open-source edition of [DropBoard](https://boboyuan.gumroad.com/l/ezzks). Open `DropBoard-Lite.html` in any modern browser (or serve it), drag a CSV in, and you get:

- **KPI cards** for every numeric column
- **Monthly trend line** from any date column
- **Ranking bars** for category columns, **histograms** for distributions, **donut chart** for categorical shares
- **Filterable data table** with instant recalculation
- Handles messy CSVs: quoted fields, BOM, CRLF, semicolon/comma/tab delimiters, currency symbols, negative numbers in parentheses, common date formats

## What's limited in Lite

| | Lite (free) | [Full version ($19)](https://boboyuan.gumroad.com/l/ezzks) |
|---|---|---|
| Rows | first 500 | unlimited |
| Export PNG / standalone HTML / filtered CSV | 🔒 | ✅ |
| 29 KB single file, 100% offline | ✅ | ✅ |
| Free lifetime updates | — | ✅ |

## Try the companion tool

[**Page2CSV**](https://boboyuan.gumroad.com/l/epknyx) ($15) — grab any table from any web page into a clean CSV in one click, then drop it into DropBoard. Web table → CSV → dashboard, no spreadsheet wrangling.

## Usage

1. Download `DropBoard-Lite.html`
2. Double-click it (works offline)
3. Drag your CSV in, or click **Load sample**
